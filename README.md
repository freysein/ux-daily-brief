# UX Daily Brief

Automated UX intelligence newsletter for internal UX specialists.

## Editorial scope

- Language: English
- Schedule: Monday to Friday
- Target: 6–9 articles per edition
- Article format: 70–100 words including UX Impact
- Editorial approval: Automated quality checks
- Empty editions: Status email is sent even with zero relevant articles

## Sources

- RSS/Atom feeds
- Subscribed email newsletters
- YouTube channels (full transcripts required for analysis)

## Technology

- Python
- Ollama (local inference)
- DuckDB
- Jinja2
- n8n orchestration

## Development status

Initial project scaffolding. No production collectors or workflows yet.

## Data and copyright

No paywall bypassing. Source-specific processing restrictions apply.
